💡 Challenges Faced

Setting up Cash on Delivery — Shopify's default payment methods required finding and configuring a COD app, which took extra research.
Currency configuration — Setting RWF (Rwandan Franc) as the store currency required navigating Shopify's payment and market settings.
Product variant management — Adding multiple color variants (Gray, Red, Blue, Black) with separate images for each variant required careful product editing.
Theme customization — Learning how to customize the free Shopify theme without coding while maintaining a professional look was a hands-on learning process.
Image optimization — Ensuring product images were clear, consistent, and well-sized across all product listings.


📚 Lessons Learned

No-code platforms are powerful — Shopify enabled building a fully functional e-commerce store without writing a single line of code.
UX matters — Simple navigation (HOME | CATALOG | CONTACT) improves the customer experience significantly.
Product presentation is key — Good product images and clear descriptions directly impact how professional a store looks.
Checkout flow design — Understanding how customers move from product → cart → checkout helped design a smoother buying experience.
GitHub for documentation — Using Markdown (README.md) to document a project is an important professional skill for developers.
E-commerce is more than design — Payment methods, shipping, and checkout flows are just as important as the visual design.
